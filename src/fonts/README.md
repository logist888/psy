# Golos Text

Вариативное начертание 400–900, SIL Open Font License 1.1 — свободное
использование, включая коммерческое. Разработан «Паратайпом» под кириллицу,
поэтому русский текст в нём выглядит так, как задумано, а не как адаптация
латинского лица.

Файл — точный сабсет под репертуар сайта (кириллица, латиница, знаки
препинания и символы вроде «₽», «≈», «№»), собранный запросом к Google Fonts
с параметром `text=`. Полное семейство весит втрое больше, а лишние глифы на
странице не появятся: `tests/fonts.test.ts` проверяет, что весь текст
контента покрыт сабсетом.

Греческая «α» в Golos Text отсутствует и отрисовывается запасным шрифтом —
это один символ в строке про надёжность методики.
