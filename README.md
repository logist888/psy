# Психотесты — SEO-лидген для MainExperts

Бесплатный сайт психологических тестов с открытой методологией. Задача сайта —
органический канал лидов для платформы [mainexperts.online](https://mainexperts.online):
посетитель проходит тест, получает честный разбор результата и может обсудить его
со специалистом платформы; психолог находит научный паспорт методики и узнаёт, что
на платформе можно вести практику.

Стратегия, исследования и решения — в [`/docs`](./docs). Начните с
[`docs/README.md`](./docs/README.md) (Executive Decision Memo) и
[`docs/strategy/lead-gen-pivot.md`](./docs/strategy/lead-gen-pivot.md) (актуальная стратегия v2).

## Принципы, зашитые в код

- **Скоринг детерминированный.** Чистая функция без времени и случайности, покрыта
  golden-тестами: изменение расчёта без обновления версии методики роняет CI.
  Нейросети в подсчёте не участвуют.
- **Ответы не хранятся.** Результат кодируется в подписанную ссылку — ПДн-поверхность
  сведена к аналитике. Прогресс живёт в `sessionStorage`.
- **Публикация только с правовым основанием.** Методика без записи в
  `content/rights-register.yaml` не проходит `validate:content` и не собирается.
- **Кризисный протокол.** Декларативные правила в методике поднимают блок с телефонами
  помощи до всего остального содержимого результата.
- **Формулировки в wellness-рамке.** Никаких диагнозов и медицинских утверждений
  (см. `docs/legal/compliance.md`).

## Разработка

```bash
pnpm install
pnpm dev                # http://localhost:3000
pnpm test               # unit + golden
pnpm validate:content   # гейт правового реестра и схемы методик
pnpm build
```

## Структура

```
content/tests/*.yaml       методики в декларативном DSL
content/rights-register.yaml  правовое основание каждой методики (гейт публикации)
content/golden/expected.json  зафиксированные результаты скоринга
src/lib/engine/            схема DSL, скоринг, кодирование результата в ссылку
src/lib/site.ts            UTM-ссылки на платформу и тексты CTA по кластерам
src/app/                   страницы: каталог, тест, прохождение, результат, паспорта
scripts/                   валидация контента, перегенерация golden
```

## Добавить методику

1. Положить YAML в `content/tests/{slug}.yaml` (схема — `src/lib/engine/schema.ts`).
2. Добавить запись в `content/rights-register.yaml` с основанием и подтверждением.
3. `pnpm validate:content` → `pnpm tsx scripts/generate-golden.ts` → `pnpm test`.

Домен настраивается при деплое через `BASE_PATH` и `SITE_URL` — приложение
домен-агностично (подпапка `mainexperts.online/tests`, поддомен или отдельный домен).
