# Strategy v2 — Пивот в SEO-лидген для MainExperts

Дата: 2026-08-19. Основание: решение владельца — сайт психотестов строится как **бесплатный SEO-лидген для mainexperts.online** (мультиэкспертная платформа; монетизация — подписки Free / Pro 2 990 ₽ / Ultima 9 990 ₽/мес с обеих сторон, комиссия с сессий не берётся). Стратегия v1 (самостоятельный SaaS «Кабинет психодиагностики», см. product-thesis.md) — **superseded**; её материалы остаются как evidence-база и опция будущей фичи платформы.

## 1. Новая цель и место в воронке MainExperts

Сайт = **органическая тестовая ячейка Потока 2** (аналог квиз-контура, но с CPL ≈ 0 за счёт SEO → прямой вклад в снижение ДРР, главного показателя).

Два типа лидов:
1. **Клиентский** (основной): Яндекс «тест на …» → прохождение → результат → CTA «обсудить результат со специалистом на MainExperts» → регистрация → активация → первая оплата → подписка (цепочка воронки ME).
2. **Экспертный** (вторичный): психолог находит сайт через professional-хвост SEO («методика X ключи нормы» — выдача пуста [OBSERVED R5]) или через клиента с результатом → CTA «ведите консультации на MainExperts».

Каждая страница теста тегируется UTM (utm_source, utm_medium=organic_test, utm_campaign={test_slug}) — атрибуция по правилу уникальных ссылок ME.

## 2. Что из исследования усиливает эту модель [evidence]

- **Флайвил «тест → специалист» — самый доказанный паттерн ниши** (R2: b17 и Psychology Today живут именно на нём; у «чистых» каталогов эта ценность утекает бесплатно). Мы строим ровно его.
- **RU SEO в do-кластерах живо** (R5 [OBSERVED]): «имя методики + пройти» ранжирует каталоги, интерактивный тест не пересказывается AI-выдачей (AIO на do-интенте ~4–15% [FACT]). Яндекс-first (74% рынка).
- **B2C-монетизация не нужна** — что снимает главный нерешённый риск v1 (WTP психологов). Сайту не нужно зарабатывать, нужно приводить.
- **psytests юридически заперт** и не может ни монетизироваться, ни продать трафик конкуренту — его аудитория достижима легальным современным продуктом.
- **Синергия E-E-A-T**: клинические YMYL-кластеры (депрессия/тревожность) требуют именованных экспертов [R5] — у MainExperts есть эксперты-психологи → их имена/ревью на страницах тестов открывают фазу 2 в клинических кластерах, куда «анонимные» каталоги не пускают.

## 3. Что остаётся обязательным (не отменяется лидген-моделью)

1. **Правовая матрица методик (R3)**: лидген для коммерческой платформы = коммерческое использование. Копировать библиотеку psytests нельзя. Библиотека: Tier A открытое ядро (IPIP, O*NET, PHQ-9*, GAD-7*, DASS-21*, WHO-5, RSES…) + собственные короткие тесты. Реестр прав (LicenseRecord) — обязателен.
2. **Кризисный протокол** (R4): interstitial с помощью при суицидальных сигналах — с первого дня, без исключений.
3. **Clinical boundary**: wellness-рамка формулировок; *клинические шкалы — фаза 2 (см. §6), в MVP только non-health + мягкий well-being.
4. **Никаких рекламных сетей** на страницах результатов (репутация + FTC/152-ФЗ-логика).

## 4. Ключевое упрощение: анонимный контур без хранения

Лидген не требует аккаунтов и хранения прохождений → **ПДн-поверхность сжимается почти до нуля** (модель psytests, легальная её часть):
- прохождение анонимно, без регистрации;
- скоринг серверный stateless: ответы не записываются, результат кодируется в подписанный URL-токен (шеринг + приватность + нулевое хранение);
- из ПДн остаются только cookie-аналитика (Метрика + консент-баннер) и опциональный email-capture «получить подробный разбор на почту» (= тёплый лид в базу ME) — вот он требует согласия и хранения, включается отдельным решением с юр. оформлением.
- ADR-002 (серверный скоринг) сохраняется — ключи закрыты; ADR-004 (AI-слой) — **исключён из MVP** (не нужен лидгену; опция фазы 2).

## 5. Воронка и KPI (в терминах ME; все цифры — [ESTIMATE]-гипотезы для проверки)

```
Organic sessions → Test start (35–50%) → Completion (70–80%) →
→ CTA view (100% завершивших) → CTA CTR (3–8%) →
→ переход на ME (UTM) → регистрация → активированная регистрация → первая оплата
```
Honest math (при 100 тыс. визитов/мес — уровень зрелого сайта M12+): ~30–40 тыс. завершений → 1–3 тыс. переходов на ME → сотни регистраций → **десятки первых оплат/мес**. Это ощутимая органическая ячейка, но не замена платному трафику: для цели «100 тыс. бесплатных / 10 тыс. платящих» сайт — один из контуров, не решение целиком.

KPI сайта: organic sessions; test start rate; completion rate; CTA CTR; переходы на ME по UTM; (на стороне ME) регистрации → активация → оплата из этого источника; вклад в ДРР (расходы контура ≈ хостинг + контент). Решения — по сквозной атрибуции до оплаты, не по CPL (правило ME).

Цели-гипотезы: M3 — 5–15 тыс. визитов/мес; M6 — 30–60 тыс.; M12 — 100–200 тыс. (вилка зависит от доменного решения и скорости индексации Яндекса; новый домен — минус 3–6 мес).

## 6. Фазы контента

- **Фаза 1 (MVP):** 20–25 легальных методик non-health + мягкий well-being (стресс/выгорание/самооценка в wellness-рамке): кластеры «тип личности», «самооценка», «выгорание», «отношения/привязанность», «ценности», «темперамент», длинный хвост открытых методик. Плюс 30–50 SEO-паспортов методик (professional-хвост → экспертные лиды).
- **Фаза 2:** клинические кластеры (тревожность/депрессия — самые конверсионные в сессию) — только с именованными экспертами MainExperts как авторами/ревьюерами страниц (E-E-A-T), выверенными формулировками (скрининг ≠ диагноз; LEGAL REVIEW) и полным кризисным контуром. Плюс AI-объяснение результата как крючок; профиль из нескольких тестов.
- **Фаза 3:** вертикали под другие типы экспертов ME (карьера/профориентация → карьерные консультанты и образовательный трек; 18+ в MVP, школьники — только после юр. проработки minors). MENA/EN-версии — по стратегии рынков ME.

## 7. Доменное решение (нужно до деплоя; рекомендация)

| Вариант | Плюсы | Минусы |
|---|---|---|
| **Подпапка mainexperts.online/tests** (reverse-proxy на отдельное приложение) | Консолидирует хостовые факторы основного домена; каждая ссылка на тесты качает весь домен | Технически чуть сложнее (proxy); контент-риски делятся с платформой |
| Поддомен tests.mainexperts.online | Простой деплой; бренд-связь | Яндекс во многом трактует поддомен как отдельный сайт — авторитет почти с нуля |
| Отдельный домен («независимый» сайт тестов) | Восприятие нейтральности → возможно выше доверие к CTA | SEO с абсолютного нуля (+3–6 мес); две площадки в поддержке |

**РЕШЕНО (2026-08-20, владелец): отдельный домен.** Сайт живёт самостоятельным SEO-проектом и переводит трафик на основной. Рекомендация подпапки не принята — и это меняет две вещи:

1. **SEO стартует с нуля**: плюс 3–6 месяцев до заметного трафика, хостовые факторы не наследуются. Прогноз §5 (M3 — 5–15 тыс. визитов) сдвигается вправо на квартал.
2. **Оформление становится своим.** На подпапке уместна была бы палитра платформы; на отдельном домене работает обратное — страница про тревожность, оформленная как реклама платформы, конвертирует в переход хуже, чем нейтральная. Отсюда собственная айдентика (`docs/design/ui.md`), а не карамельная палитра MainExperts.

Побочный эффект подпапки — адрес вида `mainexperts.online/tests/tests/big-five` — снят вместе с решением: на своём домене методика лежит по `/tests/big-five`.

Адрес задаётся переменной сборки `SITE_URL`; значение по умолчанию в `src/lib/site.ts` — заглушка до выбора домена.

## 8. Риски v2 (замещают снятые K1/K2)

| Риск | P×I | Mitigation / сигнал |
|---|---|---|
| SEO-зависимость: трафик не придёт / придёт поздно | Высокий | Длинный хвост низкоконкурентных методик; подпапка основного домена; Вебмастер-мониторинг с недели 1; параллельно тесты как посадочные для платного трафика ME (двойное использование) |
| Конверсия «результат → сессия» окажется мизерной | Высокий | A/B CTA (тайминг/тон — входные данные из синтетических интервью, проверка на реальном трафике); email-capture как промежуточная конверсия; замер сквозной атрибуции до оплаты с первого дня |
| **Центральная гипотеза скрининга ME не подтверждена** [маркировка по правилам ME-аналитики] | Высокий | Тестовый сайт масштабирует именно эту гипотезу («скрининг → платная услуга»); каждый вывод о конверсии маркировать; ранние данные сайта = дешёвая проверка гипотезы до больших бюджетов на платный трафик |
| Клинические кластеры недоступны без E-E-A-T | Средний | Фаза 2 с экспертами ME; в MVP не заходить |
| Правообладатели/юр. претензии | Средний | Только реестр прав; без классики до лицензий |
| Яндекс-алгоритм/нейроответы расширятся на do-кластеры | Средний | Интерактивность как защита; диверсификация: прямые заходы, шеринг результатов, платный трафик ME |

## 9. Что решено, что открыто

**Решено (директивы владельца):** цель — лидген для ME; рынок РФ; клиенты = и психологи (экспертный лидген), и конечные пользователи; интервью — синтетические (агентами, с маркировкой [SYNTHETIC] — см. research/synthetic-interviews.md); разработка — Claude Code, стартует немедленно.

**Открыто (не блокирует разработку):** доменное решение (§7); включение email-capture (требует юр. оформления согласия); формат «склеивающей посадочной» (делается на стороне ME); список именованных экспертов для фазы 2.

---
*Служебное (правила ME-аналитики):* затронут **Поток 2** (воронка платформы; Поток 1 не затрагивается и не агрегируется). Релевантна цель привлечения экспертов-психологов (какая из трёх целей привлечения экспертов по внутренней классификации — уточнить у владельца). Непроверенные допущения, на которых строится контур: центральная гипотеза скрининга (маркирована), конверсия «тест → сессия», сроки выхода SEO-трафика.
