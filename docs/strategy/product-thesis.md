## 4. Winning Product Thesis

**Продукт (рабочее название — «Кабинет психодиагностики»; нейминг — отдельная задача):**
SaaS-платформа для частнопрактикующих психологов РФ/СНГ: легальная библиотека валидированных методик → батареи → отправка клиенту по ссылке → детерминированный автоскоринг с нормами → профиль/динамика клиента → AI-черновик описания результатов (не диагноз, human-in-the-loop) → экспорт (PDF/CSV). Плюс публичный B2C-каталог тех же открытых методик (wellness-рамка) как SEO-воронка и среда, где клиент психолога проходит тесты.

| Элемент | Формулировка |
|---|---|
| **Product Thesis** | Психологам РФ нужен легальный, современный, AI-ускоренный инструмент психодиагностики между «бесплатным серым каталогом» (psytests) и «enterprise-платформой» (HT Lab). Мы — «PARiConnect по-русски» по цене меньше одной сессии в месяц. |
| **ICP** | Частнопрактикующий психолог/консультант РФ/СНГ (см. §2) |
| **Core Job** | Объективировать состояние и динамику клиента валидированными методиками быстро, профессионально и легально |
| **Core Value Prop** | 1–2 часа ручной работы на клиента → 5 минут; батареи + нормы + динамика + черновик описания; юридическая чистота (методики, 152-ФЗ) |
| **Why Now** | (1) База психологов растёт (вакансии ×6 к 2019, переподготовка массова), при насыщении терапевтических маркетплейсов — конкуренция специалистов ↑ → спрос на профессионализацию; (2) LLM удешевили черновик заключения на порядки — PAR уже продаёт это за $30/шт; (3) ниша пуста, а psytests юридически заперт в бесплатности; (4) регуляторное давление (152-ФЗ ужесточён 2025, закон о психодеятельности обсуждается) повышает ценность «легального» инструмента; (5) zero-click убивает контент-сайты, но не workflow-инструменты. |
| **Why Us** | Соло/малая команда + Claude Code = себестоимость разработки, при которой ниша в 40–120 млн ₽ SAM экономически осмысленна (для венчурной команды — нет, поэтому ниша и пуста). Первый ход в нише с накоплением switching cost. |
| **Why Not ChatGPT** | ChatGPT не даёт: валидированный детерминированный скоринг с нормами по полу/возрасту; батареи и сбор ответов клиентов; легальное хранение истории клиентов (152-ФЗ-контур); воспроизводимость результата; экспорт/отчёты; кризисный протокол. Психолог не может отправить клиента «в ChatGPT» и получить стандартизованный профиль. AI у нас — слой поверх скоринга, а не замена ему. |
| **Why Not Existing** | psytests: бесплатен, но без workflow, без легальности, без AI, без клиентской истории; b17: маркетплейс, тесты — трафик-приманка без проф. инструментария; HT Lab/ЭКОПСИ: enterprise, закрытые прайсы, не для частника; Иматон: офлайн-комплекты по 13–33 тыс. ₽; PAR/Pearson: не работают в РФ. |
| **Monetization** | Freemium: Free (3 активных клиента, базовые методики, ручной экспорт) → PRO 1 490–1 990 ₽/мес или 14 900–19 900 ₽/год (безлимит клиентов, батареи, AI-черновики пакетом, PDF-отчёты с брендингом, динамика). Позже: per-report кредиты (50–150 ₽) для нерегулярных; B2C расширенный отчёт 299–499 ₽; B2B-lite (команды) фаза 2+. |
| **Acquisition Engine** | (1) B2C-каталог открытых методик — SEO Яндекс по do-кластерам «имя методики» + wellness-конструктам; каждый B2C-результат имеет CTA «работаете с психологом? отправьте ему результат» и «вы психолог? заберите клиента в кабинет»; (2) контент для психологов: «научные паспорта» методик, гайды по ключам/нормам (пустая выдача [OBSERVED]) — professional-хвост SEO; (3) сообщества: TG-каналы психологов, b17-статьи, программы ДПО, супервизорские группы; (4) партнёрства с школами обучения психологов (их выпускникам нужен инструментарий). |
| **Retention Engine** | Клиентская история и динамика (switching cost растёт с каждым клиентом); батареи-шаблоны под запросы (тревога, выгорание, самооценка); еженедельный рабочий цикл; годовые тарифы. |
| **Moat** | См. §6. Главное: юридическая чистота как структурное преимущество + накапливаемые собственные адаптации/нормы + switching cost истории. |
| **Gap (честно)** | WTP RU-психологов не доказан desk research — закрывается экспериментами E1–E3 до написания продукта. |

**Non-goals:** HR/найм (AI Act high-risk логика, проф. этика), клиническая диагностика и медицинские клеймы, EN-рынок до RU-PMF, мобильные приложения, конструктор произвольных тестов (UGC), дети/подростки как аудитория MVP.

## 5. ChatGPT Threat Analysis

| Вопрос | Ответ |
|---|---|
| 1. Что пользователь может полностью заменить ChatGPT? | B2C «поговори со мной о моей личности», интерпретация «что значит мой результат», развлекательные квизы, советы. **Поэтому B2C-продукт как бизнес не строим.** |
| 2. Что ChatGPT делает хуже? | Стандартизованное измерение (нет норм, невоспроизводимо), батареи для третьих лиц, хранение/динамика, юр. ответственность, отчёты. |
| 3. Где нужен validated scoring? | Профессиональная практика (заключения, динамика, супервизия), исследования, B2B. Ядро нашего продукта. |
| 4. Где важна proprietary data? | Собственные RU-нормы (собираются с согласия из прохождений) — то, чего нет ни у LLM, ни у конкурентов. |
| 5. Где важен professional workflow? | Психолог ↔ клиент ↔ батарея ↔ отчёт ↔ динамика. LLM-чат этого не структурирует. |
| 6. Где важна compliance? | 152-ФЗ-контур, согласия, кризисный протокол — барьер для «просто чата». |
| 7. Где важна SEO discovery? | «Имя методики» do-кластеры — вход в воронку; AI не пересказывает интерактивный тест [FACT R5]. |
| 8. Где нужен longitudinal profile? | Динамика клиента между сессиями/месяцами — ключевая проф. ценность. |
| 9. Что легко скопировать? | Каталог открытых методик, лендинги, скоринг открытых шкал. |
| 10. Что можно сделать defensible? | Собственные адаптации+нормы (IP), клиентская история (switching cost), доверие проф. сообщества, партнёрства с правообладателями/ДПО. |

**AI Disruption Risk:** для B2C-каталога — **High**; для PRO-workflow — **Medium-Low** (LLM усиливает нас: черновики отчётов — наша фича, не наша смерть).
**Defensible Product Thesis:** детерминированное измерение + проф. workflow + compliance + накапливаемые нормы, с LLM как слоем объяснения — то, что генеративный чат по построению не заменяет.

## 6. Moat

**Temporary advantage (1–2 года):** первый ход в пустой нише; современный UX; AI-черновики (копируемо); цена.

**Durable moat (строится):**
1. **Юридическая чистота библиотеки** — psytests/testometrika не могут монетизироваться без пересборки библиотеки с нуля; их masse — их ловушка. Усиливается лицензиями (Иматон/Собчик) — эксклюзивные или ранние договоры поднимут барьер. Копируемо конкурентом, но требует лет и денег.
2. **Собственные адаптации и нормы** — валидированные RU-переводы IPIP-NEO и др. (наш IP) + нормы, накапливаемые из прохождений (с согласия): чем больше прохождений, тем точнее нормы, тем ценнее продукт — данные-флайвил. Нужно накопить: n≥1000+ на методику для полноценных норм.
3. **Switching cost клиентской истории** — годы динамики клиентов не переносятся к конкуренту. Усиливается со временем автоматически.
4. **Доверие проф. сообщества** (научные паспорта, именованные эксперты-ревьюеры, прозрачность) — медленно строится, медленно копируется.

Top 3: собственные нормы/адаптации, switching cost истории, юр. чистота + лицензии.

## 7. Decision Tree

```
Эксперименты E1–E5 (validation, 4–6 недель, до продуктового кода)
│
├─ E1 интервью: ≥25% готовы платить 1–2 тыс. ₽/мес И открытое ядро приемлемо
│   ├─ ДА → E3 concierge: ≥50% повторного использования?
│   │   ├─ ДА → BUILD MVP (см. prd.md) → 90-дневный gate по платящим
│   │   └─ НЕТ → инструмент не встраивается в практику → NO-GO pro-тезиса,
│   │            остаточный вариант: B2C-контент-бизнес малого масштаба (осознанно малый) или STOP
│   └─ НЕТ, но душит только отсутствие классики (СМИЛ/Кеттелл)
│       ├─ E4 лицензии доступны на разумных условиях → BUILD с licensed-модулем
│       └─ Лицензии недоступны → PIVOT: коучи/карьерные консультанты (non-health, Big Five/RIASEC)
│            └─ если и там WTP < порога → NO-GO
├─ E2 smoke: <2% конверсии в предзаказ из целевого трафика → пересмотр оффера/цены до BUILD
├─ E5 SEO-пилот: Яндекс не индексирует/не ранжирует → acquisition = сообщества-first (не kill)
└─ Внешние триггеры в любой момент:
    ├─ Закон о психодеятельности с лицензированием онлайн-инструментов → пауза + LEGAL REVIEW
    ├─ Крупный игрок (HT Lab/Ясно) выпускает self-serve кабинет → переоценка defensibility
    └─ IF всё зелёное, но через 12 мес < 150 платящих → PIVOT B2B-lite / managed-сегмент или STOP
```
