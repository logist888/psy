# PRD v2: сайт психологических тестов — SEO-лидген для MainExperts

Дата: 2026-08-19. Заменяет PRD v1 (SaaS «Кабинет психодиагностики» — в истории git; часть его наследуется фазой 2+). Основа: strategy/lead-gen-pivot.md.

## 1. Цели

- **Business Objective:** органическая лид-ячейка Потока 2 MainExperts с CPL ≈ 0: к M6 — 30–60 тыс. органических визитов/мес и стабильный поток переходов на ME с атрибуцией до оплаты; вклад в снижение ДРР.
- **User Outcome (посетитель):** бесплатно, анонимно, без регистрации пройти валидированный тест на телефоне за 3–10 минут и получить честный, понятный, не пугающий результат с осмысленным следующим шагом.
- **User Outcome (психолог):** найти корректное описание методики (паспорт: психометрика, нормы, права) и узнать, что на MainExperts можно вести практику.
- **Product Outcome:** completion rate ≥70%; CTA CTR ≥3%; сквозная атрибуция «страница теста → оплата на ME» работает с первого дня.
- **North Star:** переходы на MainExperts из завершённых результатов / неделя.
- **Non-goals MVP:** аккаунты и хранение прохождений; монетизация сайта; AI-функции; клинические шкалы с называнием расстройств; minors (<18); EN/MENA; мобильные приложения; конструктор тестов; реклама.

## 2. Требования

**Функциональные (MVP):**
1. **Каталог тестов**: главная + категории (личность, самооценка, стресс/выгорание, отношения, карьера, ценности) + теги; поиск по названию (клиентский, лёгкий).
2. **Карточка теста** (формула psytests, R1): что измеряет → автор/год/адаптация → метка происхождения источника → время/кол-во вопросов → «пример результата» до прохождения → научный паспорт (свёрнуто) → похожие тесты.
3. **Прохождение**: mobile-first, порциями по 5–9 вопросов, прогресс-бар, автосейв в sessionStorage, без JS-тяжести; выбор пола/возрастной группы там, где есть нормы.
4. **Скоринг**: серверный stateless (ответы не сохраняются), детерминированный движок с golden-тестами (architecture/test-engine.md, без AI-слоя).
5. **Страница результата**: визуальный профиль (шкалы/график), человеческое объяснение по диапазонам, «чего этот тест НЕ говорит», stateless-ссылка «поделиться результатом», кнопка «скачать/сохранить».
6. **CTA-блоки (ядро лидгена)**: (а) клиентский — после результата, тон и тайминг по инсайтам synthetic-interviews.md, с UTM `utm_campaign={test_slug}`; (б) экспертный — на паспортах методик и в футере («Вы психолог? Ведите консультации на MainExperts»); (в) вариативность текстов CTA через конфиг (подготовка к A/B).
7. **SEO-паспорта методик** (professional-хвост): отдельные страницы «{Методика}: описание, ключи, нормы, ограничения» — легальные методики полностью, охраняемые — только описательно (без стимульного материала) со ссылкой на правообладателя.
8. **Кризисный протокол**: interstitial с контактами помощи при триггерных ответах (декларативные правила в DSL); работает даже в non-health тестах на item-уровне, где уместно.
9. **Тех-SEO**: SSG/ISR, schema.org (Quiz/Article/BreadcrumbList/FAQPage), sitemap.xml с lastmod, robots.txt (AI-краулеры разрешены на паспортах — GEO-ставка), llms.txt, канонизация, ЧПУ-слаги, OG-карточки результатов для шеринга.
10. **Аналитика**: Яндекс.Метрика + серверные события (start/complete/cta_click с test_slug) без ПДн; UTM-разметка всех исходящих ссылок на ME; консент-баннер cookies.
11. **Контент-пайплайн вместо CMS**: методики как yaml/mdx в репозитории, паспорта как mdx; правовой гейт — publish невозможен без записи в реестре прав (`content/rights-register.yaml`, проверка на CI).
12. **Служебные страницы**: о проекте/методология (страница доверия), политика конфиденциальности, условия, контакты, дисклеймеры.

**SHOULD (сразу после MVP):** email-capture «подробный разбор на почту» (согласие + хранение — включается после юр. оформления; лид уходит в базу ME); конструкт-хабы non-health («всё о выгорании: тесты + что дальше»); блок «пройдите также» (второй тест за сессию — глубина); A/B-механика CTA.

**LATER (фаза 2–3):** клинические кластеры с именованными экспертами ME (E-E-A-T) + LEGAL REVIEW; AI-объяснение результата; составной профиль из нескольких тестов; кабинет психолога (наследие PRD v1 — как фича ME); карьерная вертикаль для образовательного трека ME; MENA/EN.

**NEVER:** диагнозы и медицинские клеймы; охраняемые стимульные материалы без лицензии; рекламные сети; хранение ответов без явной функции и согласия; дети <18.

**Нефункциональные:** LCP ≤2 с на мобильном 4G, страницы ≤100 КБ критического веса (статика — урок psytests); доступность WCAG 2.1 AA флоу прохождения; RU-хостинг (Метрика/152-ФЗ-контур); аптайм 99,5%; кириллица везде корректна.

## 3. Ключевые user journeys

| # | Journey | Путь | Конверсия |
|---|---|---|---|
| J1 | Клиентский лид | Яндекс «тест на выгорание» → карточка → прохождение → результат → CTA → ME (UTM) → регистрация | CTA CTR ≥3%, сквозная атрибуция до оплаты |
| J2 | Шеринг | Результат → stateless-ссылка → друг открывает → «пройти самому» | ≥5% результатов шарятся |
| J3 | Экспертный лид | Яндекс «методика X ключи нормы» → паспорт → «ведите практику на ME» | Переходы психологов по эксперт-CTA |
| J4 | Глубина | Результат → «пройдите также» → второй тест | ≥25% сессий с 2+ тестами |

## 4. Контент MVP (20–25 методик, только с правовым основанием)

- **Личность:** Mini-IPIP / IPIP-NEO-60 (собственный перевод, паспорт честно помечает статус норм), короткий типологический тест на юнгианских предпочтениях (собственные пункты, без «MBTI»-марок), темперамент (собственный на основе моделей — без охраняемых текстов Айзенка: LEGAL CHECK).
- **Well-being (wellness-рамка):** WHO-5, шкала воспринимаемого стресса (PSS-10 — проверить права; иначе собственная), выгорание (собственный опросник в wellness-рамке; MBI охраняем — не использовать), RSES-самооценка (атрибуция).
- **Отношения:** стиль привязанности (ECR-R — проверить права; вероятно, собственный короткий), язык признательности (собственный, без марок «5 love languages»).
- **Карьера/ценности:** O*NET Interest Profiler (перевод по лицензии O*NET), Portrait Values (PVQ — проверить; иначе собственный ценностный).
- **Хвост:** SD3-аналог тёмных черт (LEGAL REVIEW; иначе собственный), прокрастинация (открытые шкалы — проверить), Dark/Light triad-подобные развлекательно-научные собственные тесты (модель IDRlabs — трафик-магниты).
- PHQ-9/GAD-7/DASS-21 — **не в MVP** публичного каталога (фаза 2, клинический контур с экспертами). 

Каждая методика: запись в `rights-register.yaml` (basis: public_domain / own_work / license), научный паспорт, golden-тесты.

## 5. Метрики и события

События: `page_view, test_view, test_start, question_answer(batch), test_complete, result_view, crisis_interstitial_shown, result_share, second_test_start, cta_client_view, cta_client_click, cta_expert_click, email_capture_submit(later)`.
Дашборд-минимум: воронка J1 по каждому тесту; топ тестов по переходам на ME; когорты по кластерам запросов. Правило ME: решения — по сквозной атрибуции (регистрация → активация → оплата на стороне ME по UTM), не по CPL.

## 6. Definition of Done MVP

Сайт задеплоен (превью-домен), ≥20 методик проходятся на телефоне, golden-тесты зелёные в CI, все страницы отдают schema.org и попали в sitemap, Метрика и события пишутся, CTA с UTM ведут на mainexperts.online, кризисный протокол срабатывает (e2e-тест), privacy/условия опубликованы, реестр прав заполнен на 100% опубликованных методик, Lighthouse mobile ≥90.
