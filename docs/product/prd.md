# PRD: «Кабинет психодиагностики» (MVP)

Дата: 2026-08-19. Предусловие: PRD активируется **только после прохождения валидационных порогов** (см. §8). Основа: strategy/product-thesis.md, strategy/business-model.md.

---

## 1. Цели

- **Business Objective:** 150 платящих психологов и MRR ≥245 тыс. ₽ к M12 после запуска (Base finance/model.md); валидация нишевого SaaS с LTV/CAC ≥3.
- **User Outcome (психолог):** тестирование клиента батареей валидированных методик занимает ≤5 минут работы психолога вместо 1–2 часов; результаты легальны, воспроизводимы, хранятся с динамикой.
- **User Outcome (клиент психолога):** прохождение без регистрации по ссылке, на телефоне, с понятным и безопасным представлением результата (если психолог открыл доступ).
- **Product Outcome:** активация ≥30%, week-4 retention ≥40%, Free→PRO ≥12%.
- **KPI:** см. §9 (KPI-дерево). North Star: **число батарей, отправленных реальным клиентам за неделю**.
- **Non-goals MVP:** HR/найм; клинические диагнозы; B2C health-скрининги; дети <18; EN-локаль; мобильные приложения; конструктор произвольных тестов; marketplace психологов; API для третьих сторон.

## 3. Требования

**Функциональные (MVP):**
1. Аккаунт психолога (email+пароль, подтверждение), профиль (имя, специализация — опционально).
2. Библиотека методик: карточка-«научный паспорт» (описание, автор/год, психометрика, нормы, правовое основание, ограничения) — по формуле psytests + честность источников.
3. Батареи: сборка из методик, шаблоны (тревога/выгорание/самооценка/отношения), ссылка-приглашение клиенту (без регистрации клиента), срок жизни ссылки.
4. Прохождение клиентом: мобайл-первый, автосейв, согласие на обработку до первого вопроса, прогресс.
5. Автоскоринг: детерминированный, с нормами по полу/возрасту где есть; сырые баллы + стандартизированные (T/стены/перцентили).
6. Кабинет: список клиентов (псевдонимы/коды — минимизация ПДн), результаты, динамика (2+ замера), заметки.
7. AI-черновик описания результатов (PRO): по структурированному результату, с маркировкой AI и uncertainty; редактируемый.
8. PDF-отчёт (PRO): профиль + таблицы + текст психолога/AI-черновик + брендинг.
9. Экспорт CSV (PRO).
10. Биллинг: ЮKassa/СБП, тарифы Free/PRO мес/год, кредиты AI.
11. B2C-каталог (воронка): открытые non-health методики, прохождение без регистрации, результат по stateless-ссылке (приём psytests), CTA «отправить психологу» / «вы психолог?».
12. Админка: CMS методик (workflow Draft → Scientific Review → Rights Review → Published → Deprecated), управление пользователями, фичефлаги.

**Нефункциональные:** RU-хостинг всех ПДн (152-ФЗ); TLS + шифрование чувствительных полей at rest; RPO ≤24ч, RTO ≤8ч; p95 загрузки страницы теста ≤2с на 3G; доступность WCAG 2.1 AA для флоу прохождения; аудит-лог доступа к результатам; вопросы/ключи не раскрываются в клиентском коде (скоринг серверный — отличие от psytests, у нас ключи = актив и юр. обязательство).

**Safety/privacy (жёсткие):** формулировки — только wellness/проф. рамка (запрещённый словарь — legal/compliance.md §3.1); кризисный interstitial; health-шкалы (PHQ-9/GAD-7/DASS-21) доступны **только внутри назначений психолога**, не в публичном B2C-каталоге; данные клиентов — псевдонимизация, retention-политика, удаление по запросу; AI получает только деидентифицированные структурированные баллы.

## 6. Контент MVP: первые методики (портфель)

Критерий отбора = Search Demand × Scientific Quality × Legal Availability × Monetization × Strategic Fit × Production Cost. Только письменное правовое основание (реестр прав).

**Проф. контур (назначаются психологом):** PHQ-9, GAD-7 (официальные RU-переводы, free [FACT]); DASS-21 (RU-перевод — проверить статус, иначе собственный); WHO-5; PCL-5; RSES (Розенберг, RU-адаптации — проверить, вероятно собственный перевод); K10; ISI (проверить права) или шкала стресса PSS-10 (проверить); Mini-IPIP / IPIP-NEO-60 (собственный перевод, до валидации — с честным паспортом «перевод, нормы временные»); O*NET Interest Profiler (перевод по лицензии O*NET).
**B2C-каталог (wellness):** Big Five (IPIP-короткая форма), RIASEC-интересы, ценности (PVQ — проверить права, иначе собственный опросник ценностей), EQ-как-навык (собственный, с паспортом «экспериментальный»), стиль привязанности (ECR-R — проверить права — LEGAL REVIEW).
Итого MVP: **12–15 методик**, из них 8–10 с безусловным правовым основанием. Обоснование количества: покрывает 4 шаблона батарей и топ-кластеры B2C; больше — не нужно для проверки гипотез, меньше — не собрать батареи.
Масштабирование: 0→15 (MVP) → 15→40 (лицензии + собственные переводы, M6–M12) → 40→100 (собственные адаптации с нормами, M12–M36). Количество тестов — не самоцель; каждая методика проходит CMS-workflow с научным и правовым ревью.

## 7. Trust architecture

Научный паспорт каждой методики (что измеряет, надёжность/валидность с цитатами, происхождение норм, правовое основание, ограничения — «чего тест НЕ говорит»); именованные ревьюеры (психометрик-консультант); страница «Наука и права» (методология, реестр источников); прозрачные дисклеймеры; политика данных человеческим языком; отличие «оценка ≠ диагноз» на каждом результате. Это одновременно E-E-A-T/GEO-актив [R5: AI-движки цитируют домены с именованными экспертами].

## 9. Analytics & KPI

**Событийная таксономия:** `landing_view, signup, test_view, battery_create, battery_send, client_consent, test_start, question_answer, test_complete, crisis_interstitial_shown, result_view_pro, result_view_client, ai_draft_generate, ai_draft_edit, report_pdf_download, csv_export, subscribe_start, subscribe_renew, subscribe_cancel, credit_purchase, repeat_battery_same_client, b2c_test_start, b2c_test_complete, b2c_result_share, b2c_cta_psychologist_click`.

**KPI-дерево:**
```
Acquisition: регистрации психологов/нед (по каналам), CAC
→ Activation: % отправивших первую батарею ≤7 дн (цель ≥30%)
→ Usage: батарей/активного психолога/нед; completion rate клиентов (цель ≥75%)
→ Monetization: Free→PRO ≥12%; MRR; ARPU; кредиты
→ Retention: week-4 ≥40%; M3 paid ≥70%; повторные замеры
→ Referral: viral coefficient клиентской петли (≥0,1)
North Star: батарей отправлено реальным клиентам / неделя
```
B2B-lite (когда появится): sales cycle, win rate, ACV, expansion, churn — отдельная панель.
Инструмент: self-hosted аналитика в RU-контуре (см. architecture.md) — никаких западных пикселей на флоу результатов (урок FTC/BetterHelp [R4]).
