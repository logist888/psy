## 3. Закрыто из MVP (было четыре пункта)

**Кризисный контур** — правила заведены в шести методиках вместо одной. Пункты-триггеры выбраны не по высокому баллу шкалы, а по буквальным формулировкам дистресса: отчаяние (`podavlennost`), «ни на что не годен» и «чувствую себя бесполезным» (`self-esteem`), «никому по-настоящему не нужен» (`loneliness`), «не справляюсь» и «тону в собственных эмоциях» (`uyazvimost-k-stressu`), «не справляюсь с тем, что происходит» (`lokus-kontrolya`), плюс прежний `burnout`.

Порог везде — верхняя точка шкалы ответов: ложная тревога обесценивает блок помощи для тех, кому он нужен. В тестах на напряжение и невротизм правил нет намеренно — там нет пункта, где человек прямо сообщает о дистрессе, а срабатывание от общего балла превратило бы блок помощи в фон.

`tests/crisis.test.ts` держит это правилом: методика с пунктом про отчаяние или ненужность не проходит CI без кризисного правила на этот пункт. Партии собираются автоматически, и без страховки следующая такая методика уехала бы в публикацию молча.

**Поиск по каталогу** — клиентский, по названию и описанию. Текст запроса в аналитику не уходит: он свободный, и правило проекта — только имя события и слаг. Пишется доля поисков без результата.

**OG-карточки** — 205 картинок на сборке для тестов, результатов, тем и главной. Карточка результата намеренно не показывает баллы: ответы живут в ссылке, страница собирается в браузере, превью рисуется на сборке — узнать чужой результат оно не может, и ссылка остаётся приватной при пересылке. Шрифт лежит в репозитории, потому что `ImageResponse` системными шрифтами не пользуется.

**Контакты** — отдельные каналы для правообладателей (претензия по методике), специалистов и сообщений об ошибках, плюс явное «мы не служба помощи» с кризисными телефонами. Адрес берётся из `NEXT_PUBLIC_CONTACT_EMAIL`; пока переменная пуста, страница отправляет на платформу вместо выдуманного адреса.

Замер вскрыл два дефекта, оба исправлены: ссылки «Ещё N в этом разделе» имели высоту тач-цели 16px при требуемых 24 (регрессия правки главной), и отсутствовал фавикон — браузер писал 404 в консоль на каждой странице.

## 5. За владельцем (не решается кодом)

1. **Счётчик Яндекс.Метрики** — без него весь лидген слепой. Единственный незакрытый пункт Definition of Done.
2. **Доменное решение** (`lead-gen-pivot.md` §7): рекомендация — подпапка `mainexperts.online/tests`. Сейчас превью на GitHub Pages; сборка домен-агностична, решение можно принять в момент деплоя. Побочный эффект подпапки: у приложения есть собственный раздел `/tests`, поэтому адрес методики станет `mainexperts.online/tests/tests/big-five`. Либо смонтировать каталог в корень приложения, либо принять такой адрес — это решается вместе с доменом.
3. **Ветка по умолчанию** в репозитории всё ещё `claude/prompt-processing-51n34k`, а не `main`.
6. **Адрес для связи** — переменная `NEXT_PUBLIC_CONTACT_EMAIL`. Правообладателю нужен канал для претензии, и платформа в этой роли работает хуже прямого адреса.
7. **Сжатие на хостинге** — при деплое в подпапку убедиться, что отдаётся gzip или brotli (см. замер выше).
4. **Юр. оформление согласия** для email-capture — без него функция не включается.
5. **Именованные эксперты MainExperts** для клинических кластеров (фаза 2): без авторства/ревью выходить в YMYL-темы нельзя.

## 6. Фаза 2 (после закрытия §3–4)

- **Клинические кластеры** (тревожность, депрессия — самые конверсионные в сессию) — только с именованными экспертами, выверенными формулировками «скрининг ≠ диагноз», полным кризисным контуром и LEGAL REVIEW.
- **Составной профиль** из нескольких прохождений: один результат, собранный из 3–4 тестов. Данные для этого уже есть — история прохождений лежит локально, ответы восстанавливаются из токена.
- **A/B CTA** через конфиг (вариативность заложена в `CTA_COPY`, механики переключения нет).
- **Email-capture** «подробный разбор на почту» — тёплый лид в базу ME.
- **AI-объяснение результата** — опция, не обязательная лидгену.

## 7. Содержание: сколько ещё осталось

По замеру `scripts/ipip/select.ts` (см. `product/scaling-library.md`): 84 шкалы проходят формальные фильтры, но при ручном просмотре самостоятельных конструктов среди них около восьми — остальное синонимы уже опубликованного, и публиковать их значит стравливать свои же страницы за один запрос.

Не разобраны две страницы ключей: BFAS (маркеры «+»/«keyed» разорваны вёрсткой на строки) и CAT-PD. Плюс 33 шкалы ORAIS (внепрофессиональные интересы) короче 8 пунктов и потому отсеиваются отбором; часть из них тематически сомнительна для сайта о психологической помощи.

Практический вывод: **рост библиотеки как источник трафика близок к исчерпанию**. Дальше отдача выше у глубины страниц (профили, кризисный контур, скорость) и у клинических кластеров фазы 2, чем у ещё двадцати тестов на синонимичные черты.

## 8. Правила разработки (действуют)

Из v1 сохраняют силу и соблюдаются: одна задача за сеанс; golden-тесты обязательны при касании движка; архитектура не меняется молча; публикация методики невозможна без правового основания; фейковых данных под видом реальных не бывает.

Добавлено практикой v2:
- ссылка на шкалу-источник указывается как `СТРАНИЦА/ИМЯ` — имена шкал в пуле IPIP не уникальны;
- число пунктов и расклад прямых/обратных сверяются с источником (`tests/provenance.test.ts`);
- родовые формы в утверждениях о себе запрещены (`tests/wording.test.ts`);
- посадочная страница без собственного текста не публикуется (`tests/landing.test.ts`).
