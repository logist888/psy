# Claude Code Development Plan & Roadmap

Дата: 2026-08-19. Предусловие: код MVP стартует **после** прохождения E1–E3 (пороги — prd.md §8). До этого — только валидационные артефакты (лендинг, concierge-скрипты).

## 1. Development workflow (Claude Code)

Каждая задача: (1) прочитать релевантные доки (`/docs/architecture/*`, PRD-секцию); (2) подтвердить текущую архитектуру; (3) реализовать одну задачу; (4) прогнать тесты (golden — обязательно при касании engine); (5) ревью диффа; (6) обновить доки; (7) ADR при изменении архитектуры; (8) коммит только осознанных изменений.
Запрещено Claude Code: молча менять архитектуру; вводить зависимости без обоснования; менять скоринг без golden-тестов; коммитить секреты; обходить контроль доступа; создавать фейковые данные под видом реальных (демо-данные — только с пометкой seed/demo).

## 2. EPIC → FEATURE → TASK (MVP, ~10–12 недель после валидации)

Каждая task — размер «один сеанс Claude Code» (≤ полдня), со своими acceptance criteria (AC) и тестами. Ниже — уровень фич; декомпозиция на задачи ведётся в issues.

### EPIC 0 — Discovery/Validation (до кода; 4–6 нед, параллельно)
- F0.1 Smoke-лендинг + предзаказ (E2). AC: 3 ценовые точки, аналитика конверсии. 
- F0.2 Concierge-скоринг (скрипт: CSV ответов → баллы по 5 методикам) (E3). AC: golden-тесты уже здесь.
- F0.3 SEO-пилот: 20 статических паспортов методик (E5). AC: индексация в Вебмастере.
- F0.4 Реестр прав v0 (таблица LicenseRecord в Notion/MD) + письма E4. AC: у каждой методики MVP — basis.

### EPIC 1 — Foundation (нед. 1–2)
- F1.1 Монорепо, CI (lint, typecheck, test), окружения; RU-облако через Terraform. AC: деплой hello-app в RU-регион.
- F1.2 БД-схема ядра (data-model.md §1–2), миграции. AC: инварианты 2–4 на констрейнтах/сервис-слое, тесты.
- F1.3 Auth (регистрация/логин/сессии, rate-limit). AC: OWASP-чеклист базово, тесты.
- F1.4 Аудит-лог + шифрование чувствительных полей (KMS). AC: доступ к Result пишет AuditLog; поля answers/notes шифруются (тест).

### EPIC 2 — Core Engine (нед. 2–4)
- F2.1 DSL-валидатор (zod) + рендерер прохождения (mobile-first, автосейв). AC: 5 типов вопросов, ветвление; e2e-прохождение.
- F2.2 Скоринг-пайплайн (test-engine.md §2). AC: чистая функция, golden-тесты 12–15 методик зелёные.
- F2.3 Нормы/интерпретации + версии. AC: пересчёт создаёт новый Result (supersedes), старый неизменен (тест).
- F2.4 Кризисный протокол. AC: ненулевой q9 PHQ-9 → interstitial (e2e), CrisisEvent записан, AI для результата заблокирован.
- F2.5 Загрузка 12–15 методик MVP (контент из CMS-сидов + научные паспорта). AC: LicenseRecord у каждой; паспорта отрендерены.

### EPIC 3 — Product (кабинет психолога) (нед. 4–7)
- F3.1 Клиенты (CRUD, псевдонимы, шифрование). F3.2 Батареи + шаблоны. F3.3 Assignment: ссылка-токен с TTL, статусы. F3.4 Consent-флоу клиента (отдельные scope). F3.5 Результаты в кабинете + динамика (2+ замера, график). F3.6 Онбординг (первая батарея ≤5 мин — замер в аналитике). AC везде: e2e основного journey J1–J3.

### EPIC 4 — Monetization (нед. 6–8)
- F4.1 Тарифы/лимиты Free-PRO (фичегейты). F4.2 ЮKassa подписки + вебхуки + чеки. F4.3 Кредиты AI. AC: полный цикл оплата→продление→отмена на тестовом контуре.

### EPIC 5 — AI (нед. 7–9)
- F5.1 Провайдер-абстракция + деидентификация (белый список полей, тест «ПДн не уходит»). F5.2 Промпт-шаблоны отчёта + output-фильтры (запрещённый словарь — тест). F5.3 UI черновика с обязательной правкой. AC: черновик по golden-результату стабилен по структуре; маркировка AI.

### EPIC 6 — SEO/публичный сайт (нед. 8–10, параллелимо)
- F6.1 Паспорта методик/авторов/конструктов (SSG, schema.org, sitemap, llms.txt). F6.2 B2C-прохождение non-health со stateless-результатом + CTA-воронка. AC: Lighthouse ≥90, индексация.

### EPIC 7 — Reports/Export (нед. 9–10)
- F7.1 PDF (HTML→print, брендинг PRO). F7.2 CSV-экспорт. AC: PDF воспроизводим, кириллица корректна.

### EPIC 8 — Admin/CMS (нед. 9–11)
- F8.1 CMS-workflow методик (Draft→SciReview→RightsReview→Published→Deprecated, гейт LicenseRecord). F8.2 Пользователи/подписки/фичефлаги. AC: нельзя опубликовать без прав-основания (тест).

### EPIC 9 — Analytics/Security/Launch (нед. 10–12)
- F9.1 PostHog self-hosted + событийная таксономия PRD §9. F9.2 Бэкапы+restore-тест, мониторинг, Sentry-аналог. F9.3 Пентест-чеклист (OWASP ASVS L1), исправления. F9.4 Политики (согласия, приватность, оферта — от юриста), страница «Наука и права». F9.5 Приватная бета (10–15 design-partners) → публичный запуск. AC: SLO аптайм 99,5%, инцидент-runbook.

**Зависимости:** E2→E3→E5/E7; E4 после E3.1; E6 независим после E2.5; E8 частично раньше (нужен для загрузки контента — минимальный CMS в F2.5 через сиды).

## 3. Testing strategy

- Unit: engine (DSL-валидатор, скоринг, нормы), лимиты тарифов, деидентификация.
- **Golden scoring tests** — краеугольные (test-engine.md §3): CI-блокер.
- Integration/API: assignment-флоу, consent-гейты, биллинг-вебхуки.
- E2E (Playwright): J1 (регистрация→батарея→результат), J2 (клиент проходит на мобильном), J3 (динамика), оплата.
- Security: authz-матрица (каждый ресурс × роли), IDOR-тесты, rate-limit.
- Load: k6 на прохождение (цель: 50 RPS без деградации) — перед публичным запуском, не раньше.
- Регрессия: golden + e2e на каждый PR.

## 6. First 10 actions (конкретные, выполнимые)

1. Составить скрипт JTBD-интервью (10 вопросов + Van Westendorp) и список 50 психологов из TG-чатов/b17 для аутрича — 1 день.
2. Разослать 50 приглашений на интервью (стимул — 1 000 ₽ или ранний доступ) — 1 день, далее 3 недели интервью.
3. Собрать smoke-лендинг (одна страница, 3 тарифа, форма предзаказа, PostHog) и запустить на него трафик из 3 сообществ + 30 тыс. ₽ Директа — 4 дня.
4. Отправить письма об условиях лицензирования: Иматон, институт Собчик, Когито-Центр (+ запрос BFI-2 авторам и APA PID-5 для горизонта) — 1 день.
5. Написать concierge-скрипт скоринга 5 методик (PHQ-9, GAD-7, DASS-21, WHO-5, Mini-IPIP) с golden-тестами — 2 дня (это ядро будущего engine).
6. Провести concierge-цикл с 8–12 психологами из интервью (батарея → скоринг → шаблонный отчёт вручную) — 4 недели фоном.
7. Опубликовать 20 страниц-паспортов методик на пилотном домене, зарегистрировать в Яндекс.Вебмастере — 5 дней.
8. Получить консультацию юриста: конструкция «оператор/поручение» для пары психолог-платформа, ПЭП-согласие, выбор ИП/ООО и УСН — 1 неделя параллельно.
9. Свести результаты E1–E3 в decision-меморандум по kill-критериям K1/K2 — 0,5 дня (гейт).
10. При зелёном гейте: инициализировать монорепо (EPIC 1, F1.1) и начать спринты по плану §2.
