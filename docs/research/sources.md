## Иерархия и правила интерпретации (применялись)

- **Уровень A** (первичные документы, официальные сайты, законодательство, отчётность) — основа [FACT].
- **Уровень B** (Pew, Ahrefs/Semrush-исследования с методологией, RevenueCat, Rock Health, ВЦИОМ, BusinesStat) — [FACT по методологии X].
- **Уровень C** (Similarweb/Hypestat, Crunchbase, market-research агрегаторы) — только [ESTIMATE]; методология Mordor/MRFR/GVR признана слабой и помечена во всех местах использования.
- **Уровень D** (Reddit/форумы/обзоры) — только как сигналы поведения.
- **Уровень E** (вторичные статьи) — только при недоступности первички (16personalities отдаёт 403 ботам — цены по двум вторичным источникам, помечено).

## Зафиксированные конфликты источников

1. **Трафик psytests.org**: Hypestat ~986 тыс./мес vs Similarweb-ранг #10 255 (типично 4–7 млн/мес) vs Similarweb «3,1 млн за 3 мес». Разрешение: диапазон 1–6 млн/мес, для расчётов консервативно 1–3 млн. Оба источника — панельные [ESTIMATE].
2. **Размер global personality assessment market**: $7,4–10,7 млрд у разных фирм. Разрешение: не использован в решениях; для B2C-сегмента взят порядок $1 млрд с пометкой «низкое доверие».
3. **Рынок психоуслуг РФ**: BusinesStat 49,7 млрд ₽ (широкий скоуп) vs Коммерсантъ 20,5 млрд ₽ (только платная терапия). Разрешение: разные скоупы, оба сохранены с указанием охвата.
4. **Штраф за нарушение порядка согласия (152-ФЗ)**: 700 тыс. ₽ vs 1,5 млн ₽ в разных вторичных источниках → LEGAL REVIEW REQUIRED.
5. **16personalities premium**: $32,99/год — два вторичных источника, сайт недоступен боту. Помечено [ESTIMATE-Среднее].

## Правило одного первоисточника

Несколько сайтов, цитирующих одну цифру (например, «психологов в РФ ~100 тыс.»), считались одним evidence. Цифра числа психологов РФ признана [ESTIMATE, низкое доверие] — реестра не существует.
