# [SYNTHETIC] Синтетические интервью: психологи и конечные пользователи

Дата: 2026-08-19. **Это симуляция персон ИИ-агентами, а не полевое исследование.** Проведено по решению владельца вместо реальных интервью (E1). Служит источником продуктовых гипотез; абсолютные цифры конверсии непереносимы на живой трафик. Граундинг: `research/keywords.md`, `research/market.md`, `research/competitors.md`.

## Часть A. Психологи (8 персон)

Персоны: КПТ-Москва (30 кл/мес), психоаналитик-СПб (20 лет, «принципиально сам»), гештальт-Екатеринбург (b17-конвейер), эклектик-Новосибирск (после ДПО, обожглась на Profi), КПТ/ACT-онлайн (лист ожидания, самодельные Google Forms), детский диагност-Казань (Иматон, бумага), новичок-Ростов (1 год, psytests — «моя опора»), экзистенциальный-Москва (b17-старожил, классическая диагностика).

### Топ-5 мотиваторов регистрации психолога
1. **Тёплый лид с контекстом** — «первая сессия наполовину сделана до первой сессии». Отличие от b17/Profi, где лид холодный.
2. **Побег с контент-барщины** — у b17-зависимых привлечение стоит 6–8 часов текстов в неделю.
3. **Инструмент, а не витрина** — автоскоринг/батареи/динамика/экспорт ценны даже тем, кому клиенты не нужны.
4. **Легитимация для ДПО-новичков** — тест структурирует сессию, снижает страх некомпетентности; «какой тест при каком запросе» — самостоятельный магнит.
5. **Научность и юр. чистота** — критерий «можно ли ставить своё имя рядом с площадкой».

### Топ-5 барьеров
1. **«Плати за воздух»** — травма платных откликов Profi/продвижения b17; предоплата до доказанного потока отторгается 5 из 8.
2. **Холодный старт и безликость** — «снова буду 351-м в каталоге»; нужны счётчики живых прохождений.
3. **Репутационное соседство** — развлекательные тесты рядом с клиническими шкалами; **специфично для MainExperts: эзотерика/тарологи в соседних разделах — стоп-фактор для опытных**.
4. **Страх повторить маркетплейс** — эксклюзивность, обязательность консультаций через площадку, невозможность выгрузить данные.
5. **Скепсис к самодиагностике** — «клиент придёт с ярлыком»; детские методики в открытом доступе — красная линия.

### CTA для психологов
**Работает:** «Клиент уже прошёл диагностику — продолжите работу с готовым профилем»; «Валидированные методики с автоподсчётом и нормами»; счётчик «сколько человек прошло тесты по вашей теме за месяц»; «Готовые батареи под типовые запросы».
**Отталкивает:** «лидген», «поток клиентов», «гарантированные заявки», «монетизируйте экспертность», «станьте топ-экспертом», любые обещания дохода — весь словарь инфобизнеса.

### Закон жанра (ключевая цитата)
«После шкалы депрессии приходит человек с депрессией. После теста "какой вы кот" не приходит никто» — качество лида определяется научностью теста. Конфликт «SEO-масса vs проф. доверие» решается архитектурой каталога (раздельные разделы), а не копирайтингом.

## Часть B. Конечные пользователи (10 персон)

Персоны: 19–44 года, 9 городов, доход 30–400 тыс. ₽, 7 из 10 никогда не были у психолога (соответствует ВЦИОМ: 13% пенетрация). Запросы: тревога ×2, выгорание ×2, самопознание ×2, карьера, отношения, самооценка, депрессия.

### Ранжирование кластеров по вероятности конверсии «результат → сессия»
| Ранг | Кластер | Почему |
|---|---|---|
| 1 | **Выгорание** | Платёжеспособные (IT/бизнес), «легитимный» немедицинский повод (выгорел ≠ болен → меньше стыда), боль привязана к работе |
| 2 | **Тревога** | Максимальная боль, но аудитория моложе/беднее; страх диагноза и стыд; клик высокий, оплата режется ценой |
| 3 | **Отношения/расставание** | Максимальная уязвимость и готовность к контакту, но низкая платёжеспособность → конвертируется в лид (email), не в оплату |
| 4 | **Самопознание** | Основной объём трафика, низкая острота боли. Внутри — золотой сегмент «давно собираюсь к психологу, тест как разрешение себе» |
| 5 | **Карьера** | Слово «психолог» ломает сценарий; нужен «карьерный консультант». SERP занят EdTech, аудитория обожглась на «вам подходит аналитик данных» |

### Дизайн страницы результата (чек-лист из интервью)
1. Балл на шкале с зоной нормы («ты — вот тут»).
2. Название и происхождение методики (валидированность = доверие).
3. Расшифровка по подшкалам простым языком, без ярлыков-диагнозов.
4. Явный дисклеймер «это не диагноз».
5. **Блок «что можно сделать самому» (3–4 совета) — ДО CTA**; парадоксально повышает доверие к CTA (скептик дочитает только такой вариант).
6. CTA с ценой, лицами специалистов и слотами.
7. Сохранение результата по ссылке + «пройти снова через N недель» (динамика — главный магнит возврата).
8. Кризисные контакты при высоких клинических баллах.
9. Share: яркая карточка у типологии, приватная «отправить близкому» у клинических (реальный сценарий: муж показывает результат жене — жена и есть покупатель).

### Правила CTA для клиента
- **Тайминг:** только ПОСЛЕ интерпретации, никогда попапом поверх результата. Кнопка до объяснения = «сначала напугали, потом продают».
- **Тон:** «Разобрать результат с психологом» / «Обсудить результат со специалистом» ✅; «Записаться на терапию» ❌ (патологизация отпугивает 7 из 10, никогда не бывших в терапии).
- **Карьерный кластер:** «карьерный консультант», не «психолог».
- **Трение:** за кнопкой не каталог из 100 анкет, а 2–3 специалиста под результат; цена видна сразу; онлайн-запись без «вам перезвонят» («звонков боюсь больше, чем терапии»).
- **Анонимность:** критична для клинических кластеров; никаких «оставьте телефон до результата»; явно написать «мы не просим имя и не звоним».
- **Промежуточная ступень:** мини-разбор 500–990 ₽ или гайд на почту ловит тех, кого полный чек 3000 ₽ отсекает (3 из 10).

### Главный конкурент CTA — ChatGPT
4 из 10 персон уже носят результаты тестов в ChatGPT как бесплатному интерпретатору. Ответ продукта: интерпретация на странице должна быть лучше «средней болтовни с ботом» (по подшкалам, персонализированная), а CTA предлагать то, чего бот не даёт — живого специалиста, план, ответственность.

### Синтетическая «конверсия» (НЕ прогноз)
Кликнули бы CTA 6/10; заплатили бы 3000 ₽ сразу 2/10 (+1 условно). Реальные бенчмарки: free→paid 1–3% [RevenueCat/JobCannon], публичных кейсов «тест → терапия» в РФ нет. Переносим только **соотношение между кластерами**, не абсолютные числа.

## Часть C. Где синтетика может врать (обязательно перепроверить)

1. **Заявленное ≠ поведение.** «Я бы заплатил» у сгенерированной персоны стоит меньше, чем у живой (а там интент-инфляция ×3–5).
2. **Персоны — стереотипы.** Связка «школа → отношение к тестам» вероятно карикатурна; квоты реальной выборки по школам строить не стоит.
3. **Распределение трафика искажено.** В выборке 1 «развлекающийся» из 10; в реальном SEO-трафике их, вероятно, большинство → средняя конверсия по трафику будет много ниже.
4. **Реакция на мультиэкспертность MainExperts** («рядом тарологи») — синтетическая гипотеза с большими последствиями для бренда. Проверить на 3–5 реальных опытных психологах в первую очередь.
5. **Значимость легальности/152-ФЗ** может быть эхом документов репозитория (circular reasoning) — спрашивать открытым вопросом.
6. **Цитаты не подлинны** — нельзя брать как VoC-материал для лендинга без проверки.
7. **Систематические слепые зоны:** недооценка мусорного мобильного трафика, сезонности, страха утечки данных; переоценка роли формулировок CTA против цены и трения.
8. **Что решается только A/B-тестом:** позитивные формулировки CTA, тайминг, промежуточная ступень (мини-разбор 500–990 ₽ vs прямая продажа 3000 ₽).
