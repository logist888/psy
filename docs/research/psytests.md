## 4. Test-taking Flow

Наблюдался на Кеттелл 16PF, Люшер, СМИЛ/MMPI, Big Five 5PFQ — все 2026-08-19, все [OBSERVED]:

1. **Карточка теста**: описание методики и её истории → блок ссылок «Тест | бланк | пример» → «Автор: Raymond Cattell (1949, 1970); Адаптация: А. Г. Шмелев и др. (1987)» → плашки «✓ пройти бесплатно и анонимно», «✓ сделано по первоисточнику» → теги → раздел «Литература» (печатные издания: Иматон, Речь, КГУ и т.д.).
2. **Run-страница**: авторская инструкция → выбор варианта (форма A/B) → выбор пола и возрастной группы (для нормировок; параметры в JS: `agemin 16, agemax 90, qtotal 187, onpage 9, engine qtl`) → кнопка «НАЧАТЬ ТЕСТИРОВАНИЕ». Вопросы отдаются порциями по 9 на экран; прогресс — в sessionStorage; JS обязателен.
3. **Результат**: редирект на постоянную ссылку `/result?v=…`. Страница результата (пример 16PF): дисклеймер «результаты без участия специалистов не следует воспринимать слишком серьезно» → графический профиль (canvas) → таблица стенов по 16 факторам → разделы интерпретации → литература.
4. **Особенности выдачи**: ссылка на результат stateless — «вся информация содержится в самой ссылке и не хранится на сервере»; одинаковый результат = одинаковая ссылка; удалить/восстановить нельзя (agreement п.3.2–3.9). Опция «сохранить бланк ответов» даёт вторую ссылку с ответами.
5. **Регистрация не нужна** для прохождения [OBSERVED, agreement п.4.2]. Логин нужен только для сохранения истории (личный кабинет) или сбора данных респондентов (рабочий кабинет). Для СМИЛ прямо написано: «онлайн-версия сделана для помощи психологу в обработке данных… тест интерпретаций не выдает» — позиционирование как счётного инструмента, а не «узнай себя».

1. **Правовая уязвимость контента**: методики без лицензий, на доктрине цитирования; точечные Disallow в robots.txt на шкалы Бека выглядят как следы претензий [INFERRED]. Библиотека может «худеть» по требованиям правообладателей [OBSERVED takedown-политика].

## 12. Defensibility

**Защищаемо:** корпус из тысяч выверенных по первоисточникам реализаций с нормировками — 10+ лет ручного труда; репутация у профессиональной аудитории и позиции по тысячам навигационных запросов; данные о популярности методик; анти-скрейпинг (ключи не публикуются, AI-боты забанены).

**Не защищаемо:** сами методики — не принадлежат сайту; модель «каталог тестов» как таковая — копируема; рекламная монетизация — нулевой switching cost.

## 13. What to Copy / What Not to Copy

**Копировать:**
1. **Формулу карточки теста**: описание → автор+год → адаптация+год → метка качества источника → «пройти | бланк | пример результата» → литература → теги. «Пример результата» до прохождения — сильный конверсионный приём.
2. **Stateless-ссылки на результат** — приватность, виральность и дешёвое хранение одновременно.
3. **Прохождение без регистрации** + регистрация только ради истории.
4. **Рабочий кабинет для исследователей** (батареи, анонимные респонденты, CSV) — недооценённый B2B-клин.
5. **Систему честности источников** (метки «по первоисточнику» и т.д.) — дифференциатор доверия.
6. **Двухконтурную библиотеку** и многоосную навигацию (теги/авторы/первая строка).
7. **Лёгкий статический стек** с клиентским подсчётом — экономика и скорость.

**Не копировать:**
1. **Правовую модель «публикуем без лицензий, удалим по запросу»** — работает у анонимного ИП в РФ, но не масштабируется в коммерческий/международный продукт.
2. **Монетизацию тизерными сетями** на страницах про депрессию/суицидальный риск — репутационно токсично.
3. **Отсутствие schema.org/hreflang**, windows-1251, кодовые URL — техдолг, а не решение.
4. **Медицински чувствительные тесты без обработки кризисных результатов** (кризисных линий при высоких баллах депрессии на осмотренных страницах не наблюдалось; полные страницы результатов клинических шкал детально не проверялись — частично [UNKNOWN]).
5. **Непрозрачность владельца и «форма без ответа» вместо поддержки**.
