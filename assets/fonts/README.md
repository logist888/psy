# Шрифты для OG-карточек

`ImageResponse` рисует картинку своим движком и системными шрифтами не пользуется:
без файла кириллица в карточке превратится в пустые прямоугольники. Поэтому шрифт
лежит в репозитории — сборка на чистом раннере должна давать тот же результат.

Liberation Sans, лицензия SIL Open Font License 1.1 — свободное использование,
включая коммерческое. Файлы участвуют только в сборке и посетителю не отдаются.
